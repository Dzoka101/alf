# ALF AI-блогер — автономная контент-машина для соцсетей

AI-агент, который сам придумывает, оформляет и публикует контент в Instagram, Telegram и VK, учится на статистике и ведёт трафик туда, где он превращается в деньги.

---

## Идея (и почему именно такая)

**Ниша: премиум- и бизнес-автомобили в Москве, привязанная к реальному бизнесу ALF (аренда авто бизнес-класса).**

Большинство «AI-блогеров» пытаются заработать на рекламе и партнёрках с нуля — это медленные деньги: нужно 10 000+ подписчиков, прежде чем появится первый рубль. Здесь монетизация встроена с первого дня:

- **Один лид на аренду бизнес-авто стоит 3–10 тыс. ₽ на рынке рекламы, а один клиент приносит 90 000+ ₽/мес выручки.** Даже 2–3 клиента в месяц с контента окупают всю систему многократно.
- У ALF уже есть сайт с формой заявки (`/drivers`) — готовая посадочная страница для «ссылки в шапке».
- Контент в нише «сколько зарабатывает водитель бизнес-класса», «аренда vs покупка», «инсайды таксопарков» — вечнозелёный, виральный и притягивает ровно ту аудиторию, которая арендует машины.

**Воронка:** карусель/Reels → «ссылка в шапке» → сайт ALF (заявка) или Telegram-канал (прогрев + лид-магнит) → аренда.

**Вторичная монетизация** (подключается по мере роста):
1. Telegram-канал → продажа рекламы (от ~5 000 подписчиков: 3–15 тыс. ₽/пост).
2. Партнёрки: детейлинг, автострахование, шиномонтаж, автоподбор (CPA 500–5000 ₽).
3. Свой цифровой продукт: платный гайд/курс «Как выйти в бизнес-тариф и зарабатывать 150к+» (999–2990 ₽).

**Честно про ожидания:** гарантированных быстрых денег в соцсетях не существует. Реалистичный план: первые лиды на аренду — со 2–4 недели (за счёт Reels-охватов), стабильный поток — через 2–3 месяца ежедневных публикаций. Преимущество системы в том, что она публикует каждый день без вашего участия и стоит копейки.

## Что делает система

```
┌─────────────┐    ┌──────────┐    ┌────────────────────┐    ┌───────────┐
│  Claude API │ →  │ Рендер   │ →  │ Автопостинг         │ →  │ Аналитика │
│  генерирует │    │ карусели │    │ Instagram / TG / VK │    │ → обратно │
│  посты+Reels│    │ 1080x1350│    │ по расписанию (CI)  │    │ в промпт  │
└─────────────┘    └──────────┘    └────────────────────┘    └───────────┘
```

1. **`plan`** — Claude генерирует пачку постов: тема, подпись с CTA и хэштегами, 5–6 слайдов карусели, сценарий Reels. Учитывает статистику прошлых публикаций (какие темы «зашли» — таких делает больше).
2. **`render`** — каждая карусель рендерится в брендированные PNG 1080×1350 (Chromium, HTML-шаблоны — цвета и стиль в `config/brand.json`).
3. **`publish`** — публикация: Instagram Graph API (официальный API, без риска бана), Telegram Bot API, VK API.
4. **`analyze`** — сбор охватов/лайков/сохранений, сводка ложится в промпт следующей генерации — система самообучается на своей статистике.
5. **GitHub Actions** — всё крутится по крону в облаке бесплатно, сервер не нужен: 1 пост в день в 10:00 МСК.

Сценарии Reels сохраняются в JSON каждого поста (`reelScript`) — их можно снимать самому, отдавать монтажёру или прогонять через видеогенератор (HeyGen/Higgsfield) — это следующий апгрейд системы.

## Быстрый старт

```bash
cd agent
npm install

# 1. Посмотреть, как это работает, без единого ключа:
npx tsx src/cli.ts plan --offline   # 5 готовых постов в очередь
npx tsx src/cli.ts render           # PNG-карусели в content/media/
npx tsx src/cli.ts status

# 2. Подключить генерацию через Claude:
cp .env.example .env                # заполнить ANTHROPIC_API_KEY
npx tsx src/cli.ts plan             # свежие посты от Claude

# 3. Подключить платформы (см. .env.example) и опубликовать:
npx tsx src/cli.ts publish
```

### Автопилот через GitHub Actions

1. В настройках репозитория → Secrets and variables → Actions добавить:
   `ANTHROPIC_API_KEY`, `IG_ACCESS_TOKEN`, `IG_USER_ID`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `VK_ACCESS_TOKEN`, `VK_GROUP_ID`.
2. Workflow `.github/workflows/ai-blogger.yml` уже настроен: каждый день в 10:00 МСК генерирует (если очередь пуста), рендерит, публикует 1 пост и собирает аналитику. Запуск вручную — вкладка Actions → AI Blogger → Run workflow.
3. **Для Instagram** картинки должны быть доступны по публичному URL — репозиторий должен быть публичным (workflow использует `raw.githubusercontent.com`), либо задайте свой `MEDIA_BASE_URL` (например, папка `public/` на вашем хостинге).

### Получение токенов (кратко)

| Платформа | Что нужно |
|---|---|
| **Instagram** | Бизнес/креатор-аккаунт, привязанный к странице Facebook → приложение на developers.facebook.com → долгоживущий токен с правами `instagram_basic`, `instagram_content_publish`. `IG_USER_ID` — из `GET /me/accounts` → `instagram_business_account.id`. Лимит API: 50 публикаций/сутки — с запасом. |
| **Telegram** | Бот у @BotFather → добавить бота администратором канала → `TELEGRAM_CHAT_ID` = `@имя_канала`. |
| **VK** | Сообщество + токен пользователя-админа со scope `photos,wall` (можно через vkhost/официальную форму OAuth). |

## Структура

```
agent/
├── config/brand.json      # ниша, персона, рубрики, CTA, цвета — ЕДИНСТВЕННОЕ место настройки
├── src/
│   ├── cli.ts             # команды: plan / render / publish / analyze / run / status
│   ├── claude.ts          # генерация контента (Claude, structured outputs)
│   ├── sample-content.ts  # офлайн-набор постов для демо и работы без ключа
│   ├── templates.ts       # HTML-шаблоны слайдов (обложка / контент / CTA)
│   ├── render.ts          # HTML → PNG через Chromium
│   ├── analytics.ts       # сбор insights + сводка для самообучения
│   └── publish/           # instagram.ts, telegram.ts, vk.ts
└── content/
    ├── queue/             # очередь постов (JSON)
    ├── media/             # отрендеренные карусели (PNG)
    ├── published/         # архив опубликованного
    └── analytics/         # stats.json + summary.md
```

**Смена ниши = правка одного файла.** Вся система ниши-агностична: отредактируйте `config/brand.json` (ниша, персона, рубрики, CTA, цвета) — и тот же конвейер ведёт блог про финансы, недвижимость или нейросети.

## Стратегия запуска (первые 30 дней)

**Неделя 1 — фундамент.**
Оформить профили (аватар, шапка с оффером «Аренда бизнес-авто | Ответ за 1 час», ссылка на сайт с UTM). Залить 6–9 постов из очереди за 3 дня, чтобы профиль не выглядел пустым. Завести Telegram-канал — он «копилка» аудитории, которую не отнимет алгоритм.

**Неделя 2–3 — Reels-режим.**
Карусели дают сохранения, но охваты дают вертикальные видео. Брать `reelScript` из каждого поста и снимать 3–5 Reels в неделю (телефон + машина из парка = достаточно). Дублировать в VK Клипы и YouTube Shorts — тот же файл, тройной охват.

**Неделя 4 — первый замер.**
`analyze` покажет топ-темы. Убить слабые рубрики, удвоить сильные (система сделает это сама через промпт, но стоит проверить руками). Подключить лид-магнит: гайд в обмен на подписку в TG.

**Правила гигиены:**
- Только официальные API (как в этой системе) — никаких ботов накрутки и массфолловинга: бан аккаунта убивает весь актив.
- Отвечать на комментарии в первый час после публикации (это множитель охвата; можно поручить тому же Claude — следующий апгрейд).
- Для аудитории из РФ основные деньги — VK + Telegram: реклама в Instagram для российских рекламодателей запрещена законом (Meta признана экстремистской организацией), поэтому монетизация там — только через переходы на ваш сайт/TG.
- Помечать AI-контент там, где платформа этого требует.

## Экономика системы

| Статья | Стоимость |
|---|---|
| Генерация 5 постов (Claude Opus) | ~$0.5–1.5 за пачку |
| Рендер и публикация | 0 ₽ (GitHub Actions free tier) |
| Итого месяц ежедневных постов | **~$5–10** |

Для сравнения: SMM-агентство с таким объёмом (30 каруселей + 30 сценариев Reels в месяц, 3 платформы, аналитика) стоит 60–150 тыс. ₽/мес.
