# Лео Нейман — автономный виртуальный ИИ-блогер

**Лео — открыто виртуальный персонаж: красивый парень 28 лет, ИИ, живущий в «цифровой Москве». Он сам ведёт свои соцсети и публично идёт к цели — 10 000 подписчиков без человека за спиной.** Система генерирует его жизнь и контент, публикует в Instagram, Telegram и VK, следит за статистикой и помнит свою историю.

---

## Идея (и почему именно такая)

Виртуальные инфлюенсеры — работающая модель (Lil Miquela: 2,5 млн подписчиков и контракты с брендами; Aitana Lopez: ~10 тыс. € в месяц на рекламе). При этом мужских AI-блогеров в рунете почти нет — ниша пустая.

Три слоя, которые делают Лео сильнее обычной контент-страницы:

1. **Сюжет-реалити.** Публичная цель «10 000 подписчиков полностью сам» — это интрига, за которой следят: получится ли у кода обыграть людей в их же игре. Каждый рубеж (первая тысяча, первый хейтер, первый заработанный рубль) — готовый вирусный пост. Еженедельные отчёты с честными цифрами — контент, который невозможно скопировать.
2. **Персонаж, а не лента фактов.** Люди подписываются на личность: харизма, самоирония, «дневник ИИ среди людей». Подборку нейросетей украдут за день — Лео не украдёт никто.
3. **Открытость про ИИ как бренд.** Лео не притворяется человеком — он гордится тем, что он код. Это снимает риски маркировки синтетики и превращает раскрытие в фишку.

Плюс польза остаётся: половина контента — нейросети и промпты «от первого лица ИИ», это сохранения и рост через алгоритмы.

**Воронка:** карусель/Reels → «ссылка в шапке» → Telegram «Дневник Лео» (лид-магнит «50 промптов, которыми я пользуюсь сам») → монетизация базы.

**Лестница монетизации:**

| Этап | Подписчики TG | Источник денег |
|---|---|---|
| С 1-го дня | 0+ | Партнёрки AI-сервисов и агрегаторов нейросетей (CPA/revshare, обычно 15–40%) |
| Со 2–4 недели | 500+ | Свой продукт: «Библиотека 300 промптов Лео» / мини-гайд за 990–2 990 ₽ (пишется тем же Claude за вечер) |
| 1–3 месяц | 3 000–5 000+ | Реклама в Telegram-канале: 3–15 тыс. ₽/пост; сюжет «первый заработанный рубль Лео» — сам по себе контент |
| 3+ месяц | 10 000+ | Рекламные интеграции у персонажа (виртуальные инфлюенсеры берут за это как живые блогеры), продажа таких же AI-блогеров под ключ |

**Честно про ожидания:** гарантированных быстрых денег в соцсетях не существует. Реалистичный план: первые партнёрские выплаты — в первый месяц (копейки), первые продажи своего продукта — при 500–1000 подписчиках TG, устойчивые 50–150 тыс. ₽/мес — через 3–6 месяцев ежедневных публикаций. Преимущество системы: она публикует каждый день без вашего участия и стоит ~$5–10 в месяц, поэтому «дожить» до монетизации ничего не стоит.

## Что делает система

```
┌─────────────┐    ┌──────────┐    ┌────────────────────┐    ┌───────────┐
│  Claude API │ →  │ Рендер   │ →  │ Автопостинг         │ →  │ Аналитика │
│  генерирует │    │ карусели │    │ Instagram / TG / VK │    │ → обратно │
│  посты+Reels│    │ 1080x1350│    │ по расписанию (CI)  │    │ в промпт  │
└─────────────┘    └──────────┘    └────────────────────┘    └───────────┘
```

0. **Движок жизни** — у Лео есть память (`content/state/life.json`): настроение, сюжетные арки, последние события, счётчик подписчиков и взятые рубежи. Каждая генерация читает это состояние, продолжает историю без противоречий и возвращает «что произошло в этой главе» — память обновляется. Персонаж описан в `config/character.json` (внешность, характер, запреты).
1. **`plan`** — Claude в роли Лео генерирует главу: посты (жизнь / отчёты о цели / польза), подписи от первого лица, слайды, сценарии Reels и брифы «фото из жизни» для будущей генерации изображений. Учитывает статистику прошлых публикаций.
2. **`render`** — каждая карусель рендерится в брендированные PNG 1080×1350 (Chromium, HTML-шаблоны — цвета и стиль в `config/brand.json`).
3. **`publish`** — публикация: Instagram Graph API (официальный API, без риска бана), Telegram Bot API, VK API.
4. **`analyze`** — сбор охватов/лайков/сохранений, сводка ложится в промпт следующей генерации — система самообучается на своей статистике.
5. **GitHub Actions** — всё крутится по крону в облаке бесплатно, сервер не нужен: 1 пост в день в 10:00 МСК.

Сценарии Reels сохраняются в JSON каждого поста (`reelScript`) — в этой нише это скринкасты: запись экрана по сценарию + субтитры, 10–15 минут на ролик. Следующий апгрейд — полная автогенерация видео.

## Быстрый старт

```bash
cd agent
npm install

# 1. Посмотреть, как это работает, без единого ключа:
npx tsx src/cli.ts plan --offline   # 5 готовых постов в очередь
npx tsx src/cli.ts render           # PNG-карусели в content/media/
npx tsx src/cli.ts status

# 2. Подключить генерацию через Claude:
cp .env.example .env                # заполнить ANTHROPIC_API_KEY
npx tsx src/cli.ts plan             # свежие посты от Claude

# 3. Подключить платформы (см. .env.example) и опубликовать:
npx tsx src/cli.ts publish
```

### Автопилот через GitHub Actions

1. В настройках репозитория → Secrets and variables → Actions добавить:
   `ANTHROPIC_API_KEY`, `IG_ACCESS_TOKEN`, `IG_USER_ID`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `VK_ACCESS_TOKEN`, `VK_GROUP_ID`.
2. Workflow `.github/workflows/ai-blogger.yml` уже настроен: каждый день в 10:00 МСК генерирует (если очередь пуста), рендерит, публикует 1 пост и собирает аналитику. Запуск вручную — вкладка Actions → AI Blogger → Run workflow.
3. **Для Instagram** картинки должны быть доступны по публичному URL — репозиторий должен быть публичным (workflow использует `raw.githubusercontent.com`), либо задайте свой `MEDIA_BASE_URL`.

### Получение токенов (кратко)

| Платформа | Что нужно |
|---|---|
| **Instagram** | Бизнес/креатор-аккаунт, привязанный к странице Facebook → приложение на developers.facebook.com → долгоживущий токен с правами `instagram_basic`, `instagram_content_publish`. `IG_USER_ID` — из `GET /me/accounts` → `instagram_business_account.id`. Лимит API: 50 публикаций/сутки — с запасом. |
| **Telegram** | Бот у @BotFather → добавить бота администратором канала → `TELEGRAM_CHAT_ID` = `@имя_канала`. |
| **VK** | Сообщество + токен пользователя-админа со scope `photos,wall`. |

## Структура

```
agent/
├── config/brand.json      # ниша, персона, рубрики, CTA, цвета — ЕДИНСТВЕННОЕ место настройки
├── src/
│   ├── cli.ts             # команды: plan / render / publish / analyze / run / status
│   ├── claude.ts          # генерация контента (Claude, structured outputs)
│   ├── sample-content.ts  # офлайн-набор постов для демо и работы без ключа
│   ├── templates.ts       # HTML-шаблоны слайдов (обложка / контент / CTA)
│   ├── render.ts          # HTML → PNG через Chromium
│   ├── analytics.ts       # сбор insights + сводка для самообучения
│   └── publish/           # instagram.ts, telegram.ts, vk.ts
└── content/
    ├── queue/             # очередь постов (JSON)
    ├── media/             # отрендеренные карусели (PNG)
    ├── published/         # архив опубликованного
    └── analytics/         # stats.json + summary.md
```

**Смена ниши = правка одного файла.** Отредактируйте `config/brand.json` (ниша, персона, рубрики, CTA, цвета) — и тот же конвейер ведёт блог про финансы, недвижимость или авто.

## Стратегия запуска (первые 30 дней)

**Неделя 1 — фундамент.**
Создать аккаунты (IG + TG-канал + VK). Оформить профили: аватар (генерируется нейросетью — робот-маскот), шапка «Этот блог ведёт ИИ. Нейросети без воды: промпты, схемы, деньги», ссылка на TG. Залить 6–9 постов из очереди за 3 дня, чтобы профиль не выглядел пустым. Сделать лид-магнит «50 промптов» (генерируется Claude за один запрос) и закрепить в TG.

**Неделя 2–3 — Reels-режим.**
Карусели дают сохранения, охваты дают вертикальные видео. Брать `reelScript` из каждого поста и записывать скринкасты (OBS/телефон + CapCut для субтитров, 10–15 мин на ролик), 3–5 в неделю. Дублировать в VK Клипы и YouTube Shorts — тот же файл, тройной охват. Мета-ролик «этот аккаунт ведёт нейросеть» — первым: у него максимальный вирусный потенциал.

**Неделя 4 — первый замер и первые деньги.**
`analyze` покажет топ-темы — система сама начнёт делать больше похожего. Подключить партнёрки AI-сервисов (у большинства реферальные программы), добавить ссылки в лид-магнит и посты в TG. При 500+ подписчиках TG — выпустить платную «Библиотеку промптов» за 990 ₽.

**Правила гигиены:**
- Только официальные API (как в этой системе) — никаких накруток и массфолловинга: бан убивает весь актив.
- Отвечать на комментарии в первый час после публикации — множитель охвата.
- Прозрачность про ИИ — здесь это не риск, а бренд: помечать AI-контент, где платформа требует.
- Для аудитории из РФ основные деньги — VK + Telegram: реклама в Instagram для российских рекламодателей запрещена, поэтому монетизация там — только переходами в TG.
- Не обещать в контенте «лёгкие деньги» — это и этика, и защита от банов за мисинформацию.
